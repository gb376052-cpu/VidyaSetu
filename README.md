# 🎓 Vidyasetu - National Scholarship Portal

**Vidyasetu** is a modern, responsive national scholarship aggregation platform designed to simplify discovering central, state, and private scholarship opportunities with smart eligibility filtering and a clean dark-themed UI.

🌐 **Live Demo:** [https://gb376052-cpu.github.io/VidyaSetu/](https://gb376052-cpu.github.io/VidyaSetu/)

---

## ✨ Key Features

* **Smart Quick Filters:** Easily filter scholarships by education level, category (General, OBC, SC/ST, Minority), and state/UT.
* **Modern UI / UX:** Built with Tailwind CSS, featuring a sleek dark navy theme tailored for educational portals.
* **Responsive Layout:** Fully optimized for seamless browsing across desktops, tablets, and mobile devices.
* **Eligibility Quiz Integration:** Interactive quiz section to help students quickly identify scholarships matching their unique academic and financial profile.
* **Direct Access:** Clear views for active scholarships, deadlines, and official portal links.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, JavaScript, Tailwind CSS
* **Icons & Fonts:** FontAwesome
* **Deployment:** GitHub Pages
